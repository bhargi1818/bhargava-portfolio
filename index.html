HOW I WORK WITH AI

AI accelerates
the work.
Judgment steers it.

I’m transparent about agent-assisted implementation. My work centers on choosing the right problem, defining correct behavior, and deciding what is ready to ship.

  1. 01

    Define the contract

    Start with product behavior, data ownership, constraints, and acceptance criteria. Make frontend and backend expectations explicit.

  2. 02

    Direct and inspect

    Use agents for implementation and investigation. Evaluate their proposals against the existing system and challenge unnecessary complexity.

  3. 03

    Verify the whole path

    Check the user journey, not just a unit of code. Include failure cases, migration behavior, and the boundaries where state can disagree.

  4. 04

    Keep the reasoning

    Record decisions, tradeoffs, and what changed. Current code and tests take precedence over an old plan.
